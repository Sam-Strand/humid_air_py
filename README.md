# HumidAir

Python библиотека для расчета термодинамических параметров влажного воздуха.

## Особенности

- **Научная точность** - Реализация стандартных термодинамических формул
- **Высокая производительность** - Оптимизация с помощью Numba и NumPy
- **Поддержка массивов** - Работа со скалярами и numpy массивами
- **Объектно-ориентированный дизайн** - Интуитивно понятный API
- **Полный набор параметров** - Все основные термодинамические характеристики

## Установка
### Способ 1: Установка из репозитория (требуется Git)
```bash
pip install git+https://github.com/Sam-Strand/humid_air_py.git
```

### Способ 2: Установка готового пакета (без Git)

https://github.com/Sam-Strand/humid_air_py/releases/
